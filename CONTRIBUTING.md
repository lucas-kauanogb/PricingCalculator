# Como Contribuir

1. **Faça um Fork** do projeto.
2. **Crie uma Branch** para sua modificação (`git checkout -b feature/NovaFuncionalidade`).
3. **Faça o Commit** das suas alterações (`git commit -m 'Adiciona funcionalidade X'`).
4. **Faça o Push** para a sua branch (`git push origin feature/NovaFuncionalidade`).
5. **Abra um Pull Request** detalhando as mudanças realizadas para revisão.
